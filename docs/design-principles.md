# Design Principles

## Purpose

This document defines the visual language of the project.

Every UI decision should reinforce the feeling of luxury, editorial storytelling and timeless design.

When in doubt, choose simplicity.

---

# Design Philosophy

This website is not a technology showcase.

It is a photography-first editorial experience.

UI should never compete with photography.

Typography should feel intentional.

Whitespace should be treated as a design element.

Every screen should feel calm and premium.

---

- Sophisticated

# Design Inspirations

Take inspiration from:

- Vogue
- Dior
- Prada
- Saint Laurent
- Loewe
- Harper's Bazaar

Do not copy any brand.

Capture the feeling rather than the appearance.

---

# Color System

Background

Warm Off White

Primary Text

Near Black

Secondary Text

Neutral Gray

Accent

Soft Champagne Gold

Borders

Very Light Gray

Avoid bright colors.

Avoid saturated gradients.

---

# Typography

Use only two font families.

Display

Elegant Serif

Body

Modern Sans Serif

Typography creates hierarchy.

Do not overuse font weights.

Prefer spacing over decoration.

---

# Layout

The layout should breathe.

Use generous whitespace.

Allow photography to dominate.

Avoid unnecessary cards and containers.

Do not force everything into grids.

Mix structured and asymmetrical layouts.

---

# Photography

Photography is the hero.

Never crop awkwardly.

Respect composition.

Allow images to extend naturally.

Avoid placing every image inside cards.

Use edge-to-edge imagery where appropriate.

---

# Buttons

Buttons should be understated.

No oversized buttons.

No excessive shadows.

Hover states should feel elegant.

---

# Navigation

Minimal.

Transparent over hero.

Fullscreen menu on mobile.

Navigation should never distract from the photography.

---

# Sections

Every section should have a purpose.

Avoid filler content.

Use visual rhythm.

Alternate quiet and visually rich sections.

---

# Responsive Design

Desktop, tablet and mobile are equally important.

Do not simply stack desktop layouts.

Recompose sections where necessary.

---

# Visual Consistency

Spacing

Typography

Image treatment

Section rhythm

Margins

Padding

All should remain consistent throughout the project.
